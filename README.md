# Expense-Tracker-App
A simple and responsive Expense Tracker App built using HTML, CSS, and JavaScript.This application helps users manage their daily income and expenses efficiently with real-time balance updates and data persistence using LocalStorage.

# Objectives
* Add and delete income/expense items
* Real-time calculation of total balance, income, and expenses
* Clean and responsive user interface
* Data persistence using browser LocalStorage
* User-friendly design for easy expense tracking
# Web Technology
* HTML5
* CSS3
* JavaScript
# Tools
 VS code
# Output
* Track income and expenses
* View spending statistics
* Analyze monthly transactions
* Monitor financial balance
